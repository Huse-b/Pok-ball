# 精灵球 · POKÉ LAB

这是一个可在手机或电脑浏览器中运行的 3D 精灵球作品。红色上盖、白色下壳、背部铰链、前侧按钮、内衬、卡扣与能量环均为独立建模结构。

## 打开成品

用新版 Chrome、Edge 或其他支持 WebGL 2 的浏览器打开 `精灵球-3D互动.html`。页面内置全部代码、模型与效果，不需要网络、服务器或账号。

- 点击球心按钮或底部「展开 / 闭合」控制球盖。
- 单指拖动 / 鼠标拖动可旋转模型。
- 双指捏合、鼠标滚轮或左下角 + / − 可缩放。
- 「捕获演示」播放投掷、开盖吸收、闭合摇晃和捕获成功动画。
- 「释放能量」打开球盖，播放粒子与能量环效果。
- 左下角的声音按钮可开启合成音效，默认静音。
- 左下角回转箭头恢复初始视角。
- 桌面快捷键：空格开合、C 捕获、R 释放、+ / − 缩放、Esc 关闭指南。
- 页面支持减少动态效果的系统偏好，切到后台时暂停绘制。

## 3D 模型

`Pokeball.glb` 是独立的 glTF 2.0 二进制模型，约 1.53 MB，54,788 三角面，80 个网格对象，11 个 PBR 材质，无外部纹理。可以导入 Blender、支持 glTF 的建模软件或游戏引擎。

上盖在 `Lid_Hinge` 节点下，以背部铰链为轴转动。动画 `Pokeball_Open_Close` 持续 3 秒，包含闭合 → 打开 → 闭合。页面中的「下载 3D 模型」也能导出相同文件。

## 可继续修改的源文件

- `model.js`：独立建模函数 `createPokeball(THREE)`；通过 `setOpen(0..1)` 和 `setEnergy(0..1)` 控制开合和发光。
- `app.js`：场景、灯光、触摸手势与交互动画。
- `index.template.html`：中文界面与手机布局。
- `export-model.mjs`：生成带动画的 GLB。
- `build.mjs`：打包自包含 HTML。
- `verify.mjs`：基于 Playwright 的浏览器交互验证。

技术栈：Three.js 0.170.0、esbuild 0.24.0；检查使用 Playwright 1.49.1。源文件按本次手机环境生成，导出与构建脚本默认产出目录为 `/sdcard/Download/DSH-Go`；移到电脑后可将这两个脚本中的产出目录改成你自己的路径。
